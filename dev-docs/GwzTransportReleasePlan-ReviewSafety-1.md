- *Narrowing to `local` only.* Removes the test-only `cli` placement from scope; explicit `cli` requests keep G4's refuse-before-effect rule in the placement design (no binding is installed in production today), so no new native fallback opens. Blast radius shrinks.

Residual note 1 asks the text to say so; not a degraded path.
- *§6(b) per-repository "that main".* gwz-cli's release lineage merges main but pins gwz-core by registry version (`gwz-cli/scripts/release.py`), and gwz-core tags main directly, so the per-repository rule is enforceable at each release script. A lineage patch that cherry-picks unreviewed ordinary-path code from main is bound by L1-27 ("only the intended delta") and L3-13's independent release review, both cited. No gap.
- *TR1.3's `/tmp` fallback rule.* "Refused unless the directory already exists with that owner and mode" is fail-closed on a squatted or mis-owned directory. On first use with no directory at all, the safe reading is that no listener answers, auto-start's host creates the directory 0700, and the client then verifies and connects; the unsafe-for-usability reading (refuse outright) is a stuck path for users without `XDG_RUNTIME_DIR`, recoverable by a manual `server --start` or `--no-server`. It never fails open. Residual note 2.
- *TR2.1's S3.3 clause.* Offering the production-graph regression or `--max-retries 0` for the two-clock evidence preserves the timeout plan's gate; retry cannot mask a stall in that evidence.
- *TR3.2's token revocation.* Reversible (a new token can be minted); trusted publishing can be configured against the existing placeholders. Removing workflows is reversible in git. No new irreversible step.
- *Phase 10 step 1 via trusted publisher.* Preconditioned by S2.3's exit (a configured trusted publisher per name), on Phase 10's dependency path. Sound.
- *Phase 7's new exit rows.* Require a second local user account on each platform's runner; feasible on GitHub runners and dabeest, not a text problem.
- *Disclosure.* Redaction widened (private-member names); the TR1.5 notice names the switch, not a value; server-log rules unchanged; the squatted-listener test asserts zero bytes. No new disclosure path.
