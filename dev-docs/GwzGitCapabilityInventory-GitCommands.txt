GWZ Git command-universe baseline
=================================

Captured 2026-09-20 in gwz-dev.  This is a reproducibility companion for
GwzGitCapabilityInventory.md; it is not a product allow-list.

Installed Git:
  git version 2.52.0

Commands used to capture the baseline:
  git --list-cmds=builtins
  git --list-cmds=main
  git help -a

`builtins` count: 146.  `main` count: 177.  `main` includes commands in the
Git exec directory, including script and protocol helpers.  `git help -a`
also reports documented user-facing categories, internal helpers, and the
currently installed external command `filter-repo`.  Git aliases and external
git-* programs are not part of the stable universe: aliases come from the
user's configuration and external programs vary with PATH.

The report's auditable appendix classifies the 184-name union of the 177-name
`main` set plus the seven names visible in `git help -a` but outside that set:
`citool`, `filter-repo`, `gitk`, `gitweb`, `gui`, `scalar`, and `svn`.
